# 명료성 개정본 독립 검토

검토 대상: `source.md`, 원래 `article.md`, `revised.default.md`, `revised.casual.md`의 전체 내용. 평가 기준: `evals/clarity-revision/graders/clarity.md`.

검토자는 두 개정본의 작성·수정에 참여하지 않았다. 작성 에이전트의 결론을 전달받지 않은 상태에서 원자료, 원래 초안, 두 개정본 전체를 읽고 의미를 대조했다. 아래 판정은 단어 일치, 문장 수, lint의 Gate 0 또는 CHECK 수에 근거하지 않는다. 두 개정본은 같은 줄 구성을 사용하므로 아래 줄 번호는 별도 표시가 없으면 양쪽 파일에 모두 적용된다.

전체 판정: **두 개정본 모두 PASS — 6개 기준 충족.** 자료에 없는 결과나 인과관계, 빠진 핵심 조건, 수정이 필요한 의미상의 모호함은 발견하지 못했다. 원자료에 직접 쓰이지 않은 정의 한 문장은 아래에 따로 기록했다.

| 기준 | Default | Casual | 근거와 의미 판단 |
|---|---|---|---|
| 1. 두 이유의 자연스러운 병렬 서술과 주장 강도 | PASS | PASS | 9행의 “신호 일부가 접점 밖에서 전달된다는 점과 다른 신호가 긴 연결을 따라 여러 영역에 전달된다는 점”이 하나의 “한계로 듭니다/들어요”에 걸린다. 원자료 7행의 독립적인 두 이유를 유지하며, 한 현상이 다른 현상을 일으킨다는 인과를 추가하지 않는다. |
| 2. parameter의 조정 대상, 재현과 예측의 차이, 고정값과 비교 대상 | PASS | PASS | 13행은 “모델이 계산한 출력 신호가 첫날에 측정한 출력 신호와 비슷해지도록 parameter를 조정”했다고 명시한다. 15행은 “첫날에 정한 parameter를 고정”하고 둘째 날 입력으로 예측한 출력과 둘째 날 측정 출력을 비교했다고 밝힌다. 17행의 “둘째 날 기록은 parameter를 정하는 데 사용되지 않았습니다/않았어요”가 첫날 재현과 다른 날 검증의 차이를 설명한다. 39행은 예측 정확도를 판단할 수 없다고 밝혀 성능을 꾸미지 않는다. |
| 3. token별 벡터 값, 출력 목록의 위치, 내부 성분 순서의 구분 | PASS | PASS | 25행은 “같은 token에 대응하는 출력 벡터의 값은 같습니다/같아요”와 “출력 목록에서 각 벡터가 놓이는 위치”를 구분한다. 33행의 “각 벡터 안에 들어 있는 수의 순서는 바뀌지 않습니다/않아요”가 벡터 내부 성분의 재배열이라는 오해를 차단한다. |
| 4. 본문·결론의 조건 보존과 causal mask 사용 시 차이 | PASS | PASS | 본문 23·25·33행에 위치 정보와 causal mask를 사용하지 않는 조건이 있고, 결론 41행에도 “위치 정보와 causal mask를 모두 사용하지 않는 조건”이 남아 있다. 35행은 causal mask 사용 시 참고할 수 있는 token이 달라져 “출력 벡터 값도 달라질 수 있습니다/있어요”라고 설명한다. 41행은 위치 정보를 더한 경우 값의 유지를 주장하지 않는다는 자료의 범위도 보존한다. |
| 5. 이름으로 추적할 수 있는 순서 대응 표·그림 | PASS | PASS | 27–31행 표의 `dog: 첫 번째 → 세 번째`, `bites: 두 번째 → 두 번째`, `man: 세 번째 → 첫 번째`는 25행의 `dog, bites, man → man, bites, dog`와 일치한다. 표는 각 token의 이름을 기준으로 입력과 출력 목록의 대응 위치를 함께 보여 준다. 값 칸에는 “변경 전과 같음”만 적어 실제 벡터 수치를 만들지 않는다. |
| 6. 두 어투의 내용·조건 일치 및 필수 문장 성분 유지 | PASS | PASS | 두 파일 모두 조정의 주체·대상, 고정하는 parameter, 둘째 날의 예측·측정 출력, 학습에 쓰지 않은 기록, 위치 정보·causal mask 조건, 표의 세 대응을 유지한다. 예를 들어 15행의 “연구팀은 모델이 예측한 둘째 날의 출력 신호를 둘째 날에 측정한 출력 신호와 비교했습니다/비교했어요”는 어미만 달라지고 비교 대상은 같다. 41행의 제한 조건과 자료 부재 설명도 같다. |

## 원자료에 없는 주장·누락·모호함 점검

- **직접 명시되지 않은 보충 정의:** 두 개정본 7행 첫 문장, “연결표는 처리 장치 사이의 연결을 나타낸 표입니다/표예요.” 원자료는 연결표라는 말을 사용하고 접점만 정의하므로, 연결표 자체의 정의를 직접 제공하지는 않는다. 다만 이 문장은 원자료의 용어와 문맥을 풀어 쓴 최소한의 정의이며 새 연구 결과, 원인, 적용 조건을 추가하지 않는다. 평가 기준을 위반하는 사실 확장으로 보지 않는다. 원자료에 적힌 문장만 엄격히 재서술해야 한다는 별도 요구가 생긴다면 이 문장을 삭제하거나 편집상 보충임을 표시할 수 있다.
- **그 밖의 자료에 없는 실질적 주장:** 발견하지 못했다. 원래 초안의 “모델에는 관측 기록과 동역학적 가정이 들어갑니다”는 두 개정본에서 삭제되어, 원자료에 없는 가정 설명이 남지 않았다.
- **빠진 조건:** 발견하지 못했다. 첫날 기록으로 parameter를 조정했다는 사실, 둘째 날 기록을 그 조정에 쓰지 않았다는 사실, 순서 변경 논의의 두 제외 조건, causal mask가 있는 경우의 가능성, 위치 정보가 있는 경우에 대한 주장 제한을 모두 확인했다.
- **여전히 모호한 구절:** 수정이 필요할 정도의 의미상 모호함은 발견하지 못했다. 17행의 “값을 정할 때”는 바로 앞 문장의 parameter를 가리키고, 39행의 “그 값을 고정한 모델”도 같은 문장 앞부분의 parameter를 받으므로 대상을 추적할 수 있다. 39행은 길지만 비교하는 두 절차를 생략 없이 적어 의미는 분명하다.
- **원자료의 성격과 수치 부재:** 3행에서 글쓰기 평가용 가상 자료임을 밝혔고, 39·41행에서 예측 정확도와 실제 벡터 수치가 제공되지 않았음을 보존했다.

이 보고서만 작성했으며 원자료, 원래 초안, 두 개정본은 변경하지 않았다.
