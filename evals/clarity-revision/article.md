# 처리 모델을 확인하는 방법

## 연결표의 범위

연구팀은 연결표의 한계로 신호 일부가 접점 밖에서 전달된다는 점을 듭니다. 다른 신호가 긴 연결을 따라 여러 영역에 전달된다는 점도 듭니다. 접점은 두 처리 장치가 직접 연결되는 지점입니다.

## 기록으로 맞추고 확인하기

모델은 입력 신호를 받아 출력 신호를 계산하는 식이며 parameter는 그 식에서 조정할 수 있는 값입니다. 모델에는 관측 기록과 동역학적 가정이 들어갑니다. 기록에 parameter를 맞추는 일은, 맞출 때 사용하지 않은 결과를 예측해 보는 검증과 다릅니다. 둘째 날에는 값을 고정합니다.

## 순서를 바꾼 입력

token은 입력 목록의 개별 항목이고 벡터는 여러 수를 순서대로 담은 목록입니다. 여기서는 위치 정보를 더하지 않고 causal mask도 사용하지 않습니다. causal mask는 각 token이 자신보다 뒤에 있는 token을 참고하지 못하게 하는 제한입니다. 입력 token의 순서를 바꿔도 token마다 나오는 출력 벡터는 그대로이고 그 token을 따라 자리만 옮깁니다. causal mask를 사용하면 참고할 수 있는 token이 달라집니다.

## 마치며

관측 기록과 검증은 구분해야 합니다. 입력 순서를 바꿔도 출력 벡터 값은 같습니다.
