# 설명용 처리 모델 노트

이 노트는 글쓰기 평가를 위해 만든 가상 자료다. 실제 연구 결과로 인용하지 않는다.

## 연결을 넘어 동작을 보는 이유

한 연구팀은 연결표만으로 신호 전달을 설명하기 어려운 이유로 두 가지를 든다. 신호 일부는 접점 밖에서 전달된다. 또 다른 신호는 긴 연결을 따라 여러 영역에 전달된다. 두 이유가 서로의 원인이라는 주장은 없다. 접점은 두 처리 장치가 직접 연결되는 지점이다.

## 관측 기록과 예측 기록

모델은 입력 신호를 받아 출력 신호를 계산하는 식이다. parameter는 그 식에서 조정할 수 있는 값이다. 연구팀은 첫날의 입력 신호를 모델에 넣고, 계산한 출력 신호가 첫날에 측정한 출력 신호와 비슷해지도록 parameter를 조정했다. 첫날의 출력 신호를 재현했다는 사실만으로 다른 날의 출력을 예측한다고 결론 내릴 수는 없다.

연구팀은 parameter를 고정한 채 둘째 날의 입력 신호로 출력 신호를 예측했다. 그 예측을 둘째 날에 측정한 출력 신호와 비교했다. 둘째 날 기록은 parameter를 정할 때 사용하지 않았다. 예측이 실제 측정값과 얼마나 일치했는지는 이 자료에 없다.

## 입력 순서와 출력 위치

token은 입력 목록의 개별 항목이다. 이 설명의 token 이름은 dog, bites, man이다. 모델은 모든 token을 함께 참고해 token마다 출력 벡터를 계산한다. 벡터는 여러 수를 순서대로 담은 목록이다.

여기서는 token에 위치 정보를 더하지 않고 causal mask도 사용하지 않는다. causal mask는 각 token이 자신보다 뒤에 있는 token을 참고하지 못하게 하는 제한이다. 이 조건에서 입력 목록의 순서를 dog, bites, man에서 man, bites, dog로 바꾸면 각 token에 대응하는 출력 벡터의 값은 같다. 각 벡터가 출력 목록에 놓이는 위치는 해당 token의 입력 위치와 함께 바뀐다. dog의 벡터는 첫 번째에서 세 번째로, man의 벡터는 세 번째에서 첫 번째로 옮겨진다. bites의 벡터는 두 번째에 남는다. 벡터 내부 성분의 순서를 바꾼다는 뜻은 아니다. 실제 벡터의 수치는 이 자료에 없다.

causal mask를 사용하면 순서 변경으로 참고할 수 있는 token이 달라져 출력 벡터 값도 달라질 수 있다. 위치 정보가 있는 경우에 대해서는 이 자료에서 같은 값이 유지된다고 주장하지 않는다.
