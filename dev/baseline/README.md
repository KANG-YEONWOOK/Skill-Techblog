## 후처리 반복 후보 (0.4.0)

`skills/techblog/scripts/revise_ko.py repeats`가 내는 반복 후보가 사람 글에서 몇 개 나오는지 `repeats_stats.py`로 쟀다. 후보는 판정이 아니라 후처리에서 다시 읽을 위치라서, 사람 글 절반 이상에서 후보가 0개이고 p90이 2개 이하가 되도록 규칙을 정했다. 대상은 default 그룹(2022-11-30 이전 합니다체 글) 57편 중 캐시에 다시 모은 52편이다. 당근 글 5편은 Medium RSS가 2025년 이후 글만 돌려줘서 다시 모으지 못했다.
