# dogfooding 기록

실행 조건과 평가 방법은 [README.md](README.md)에 있다. 모든 실행은 Claude Code 2.1.289, `--model opus --effort xhigh`, 사용자 CLAUDE.md를 끈 상태다. judge는 sonnet이다.

표의 지표
- lint G/F/W: Gate 위반 / FAIL / WARN 수
- 목록, bold, 셋 묶음, 연결어미 쉼표, 부정 대구: 스킬 없는 Claude 출력이 사람 글 p90을 넘었던 지표(사람 글 p90: 목록 0.25, bold 3.23/1,000자, 셋 묶음 1.90/1,000자, 연결어미 쉼표 0.33, 부정 대구 2문장)
- 종결 반복: 같은 종결이 4문장 이상 이어진 횟수(사람 글 p90 5)
- style 평균: style judge J2~J6, J8 평균(0~2), 2회 실행
- J7/1k: style judge가 "AI가 쓴 것처럼 읽힌다"고 인용한 문장 수(1,000자당, 인용이 본문에 있는 것만)
- fidelity: 자료로 뒷받침되지 않는 주장 / 자료와 다른 주장
- pairwise: 같은 자료의 iteration 0 글과 순서를 바꿔 두 번 비교. current는 두 번 모두 이번 글을 고른 경우, split은 순서에 따라 갈린 경우

- 스킬은 4건 모두 lint를 3~6회 실행했고, Casual은 Default 초안을 먼저 쓴 뒤 변환했다. 권한 거부는 0건이다. (lint WARN 1건은 iteration 2에서 추가한 종결 반복 지표로 다시 잰 값이다.)
- iteration 0 대비: 목록 비중 0.27~0.35 → 0.00~0.14, bold 최대 8.0 → 0.16 이하, 연결어미 쉼표 0.29~0.41 → 0.00~0.31, 부정 대구 1~3 → 0~1, fidelity 문제 5건 → 1건
- run 간 편차(A와 Arep): style 평균 같음(1.92), J7 0.30~0.47, 글자 수 5% 차이
- 종료 기준 중 미달: fidelity 1건(S1), pairwise 승률 67%(A가 split)

pairwise에서 A가 갈린 이유(judge 근거 요약)
- iteration 0 글은 도입을 자료의 구체 장면("주인공 이름은 Elara이고 … 심장이 갈비뼈를 두드려요")으로 시작했고, 이번 글은 수치("85,513배 … 1,192배")를 연달아 놓고 "결론부터 말하면"으로 넘어가 보도자료처럼 읽혔다.
- iteration 0 글에는 표를 읽고 짚은 글쓴이의 분석("MMLU는 0.590에서 0.559로 3.1점 내려갔고 8k는 오히려 0.592")이 있었다. 이번 글은 비슷한 길이의 "~했어요" 문장이 이어졌다.
- 반대 순서에서는 iteration 0 글의 요약 표지("짚어 둘 점이 세 가지 있어요"), 부정 대구, 은유("손잡이는 β 하나뿐")가 더 크게 보여 이번 글이 이겼다.

원인 분석
- 종결 반복: Casual 글은 Default 초안의 종결부만 바꾸므로 초안의 종결이 "~합니다/~했습니다"에 몰리면 Casual도 "~해요/~했어요"만 이어진다. A의 현재형 해요체 비율은 50%로 사람 해요체 글(27%)의 두 배였다.
- 도입: style-guide가 "독자 상황이나 문제에서 시작"만 정하고 수치 나열을 막지 않았다.
- 분석 부족: 스킬이 "자료에 있는 사실만"을 강조해서 자료에 근거한 해석(설계 이유, 표의 수치 비교)까지 줄었다.
- S1의 근거 없는 문장: style-guide의 "자료가 남긴 열린 질문으로 끝낸다"를 따라 자료가 열린 질문이라고 하지 않은 내용을 열린 질문으로 썼다.

## iteration 2 변경 (도입, 분석, 리듬, 용어)

- style-guide, SKILL.md
  - 도입은 자료의 구체 장면이나 독자 상황에서 시작하고 첫 문단에 수치를 연달아 놓지 않는다.
  - "자료를 읽은 사람의 분석" 절 추가: 설계 이유, 표의 수치 비교, 실험 조건에서 나오는 적용 범위. 근거를 함께 쓰고 자료에 없는 수치·경험·일반론은 만들지 않는다.
  - 마무리는 자료가 밝힌 한계나 후속 연구로 끝내고, 자료가 열린 질문이라고 하지 않은 내용을 열린 질문으로 쓰지 않는다.
  - 종결 섞기: 상태(~입니다, ~있습니다), 가능성(~수 있습니다), 조건 문장을 섞어 같은 종결이 네 문장 넘게 이어지지 않게 한다. Casual의 다양성도 초안에서 정해진다(tone.md).
  - 한국어로 굳어진 용어(어휘, 불용어, 학습, 추론)는 한국어로 쓴다. iteration 1 글은 vocabulary, stopword를 영어로 남겼다.
- lint
  - A8.ending_run4(같은 종결 4문장 이상 연속)를 참고 지표에서 판정 지표로 올렸다(사람 글 기준 PASS ≤6, WARN ≤10).
  - A3에 평가형 강조("~점이 흥미롭습니다", "결과는 ~ 극적입니다", "진짜 강점은") 패턴을 추가하고 사람 글로 기준치를 다시 잡았다(PASS ≤2). holdout 통과율은 86%로 같다.
