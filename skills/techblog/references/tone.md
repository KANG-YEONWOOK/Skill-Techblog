# 어투 규칙: Default(합니다체)와 Casual(해요체)

## 원칙

- 내용은 Default 초안에서 정한다. Casual은 그 초안의 문장마다 종결부(마지막 1~2 어절)만 바꾼 결과다. 어투를 고르는 단계가 내용을 고르는 단계에 끼어들지 않게 하려는 순서다.
- 문장을 나누거나 합치지 않는다. 문장 순서, 수치, 고유명사, 영문 토큰, 인용, 괄호 내용, 부정 표현은 그대로 둔다.
- 변환한 뒤 `scripts/tone_check.py <draft> <output>`으로 확인한다. 변환 뒤에 고칠 것이 생기면 종결부만 고친다. 종결부 밖의 문제는 Default 초안을 고치고 그 문장을 다시 변환한다.

## 두 어투에서 똑같이 두는 부분

- 헤딩: 명사구("측정 방법"), "~하기"("반복 표현 찾기"), 해라체 질문("반복 표현은 어디서 생길까")으로 쓴다. 헤딩에는 합니다체·해요체 종결을 쓰지 않는다.
- 코드 블록, 인라인 코드, 표, 출처를 그대로 옮긴 인용(blockquote), 링크 텍스트
- 명사구 목록 항목("비교 기준: Reddit 창작 글"). 한 목록은 전부 명사구로 쓰거나 전부 문장으로 쓴다.
- "~할까요?" 질문. 카카오 합니다체 글에서도 1.0% 쓰여서 두 어투 모두 허용한다.
- 본문에는 "~함", "~음" 같은 개조식 종결을 쓰지 않는다.

## Default 종결(합니다체)

사람 글 baseline(2022-11-30 이전 합니다체 글 57편, 서술 문장 4,709개)의 분포: ㅂ니다 현재형(합니다, 됩니다) 32%, ~었/했습니다 22%, ~있습니다·없습니다 12%, ~입니다 10%, ~ㄹ 수 있습니다 10%, ~습니다 현재형(같습니다) 5%, ~겠습니다 3%, ~것입니다 2%, "~할까요?" 1%.

쓰지 않는 표현: ~하는 바입니다, ~하고자 합니다(사람 글 0.1%), ~라 할 수 있겠습니다, ~것으로 사료됩니다, 해라체(~다), 개조식(~함, ~음). 이 표현들은 해요체로 자연스럽게 옮길 형태가 없다.

## Casual 종결(해요체)

사람 글 baseline(2024-06-30 이전 해요체 글 31편, 서술 문장 2,522개, 대부분 당근)의 분포: ~었/했어요 28%, 현재형 ~해요/~어요 27%, ~있어요·없어요 11%, ~이에요/예요 8%, ~수 있어요 6%, ~죠 3.4%, ~는데요 3.4%, ~ㄹ게요 2.9%, "~할까요?" 1.4%, ~거예요 1.4%, ~고요 1.4%, ~세요 1.3%, ~나요 1.0%, ~거든요 0.2%. 2026년 토스 순수 해요체 글에서는 ~거든요가 1.7%였다.

## 종결이 한쪽으로 몰리지 않게 하기

Casual은 Default 초안의 종결부만 바꾸므로, Casual 글의 종결 다양성은 초안에서 정해진다. 초안의 종결이 "~합니다/~됩니다"에 몰려 있으면 Casual 글도 "~해요/~돼요"만 이어진다. 사람이 쓴 해요체 글은 과거형 28%, 현재형 27%, ~있어요 11%, ~이에요 8%, ~수 있어요 6%로 섞여 있고, 가장 많은 종결이 서술 문장의 52%를 넘는 글은 5% 미만이다(lint A8.ending_top_share).

- 초안을 쓸 때부터 상태 문장(~입니다), 존재 문장(~있습니다), 가능성 문장(~수 있습니다), 과거 문장(측정했습니다)을 섞는다.
- 변환할 때 "~해요"가 이어지는 구간에서는 아래 허용 변형의 조건에 맞는 문장을 찾아 ~죠, ~거든요, ~는데요를 쓴다. 변형은 각 4% 이하, 합쳐서 10% 안팎이다. 조건에 맞지 않는 문장에 억지로 쓰지 않는다.

## 허용 변형

해요체 글이 ~어요로만 끝나면 단조롭다. 아래 변형은 실측 비율(각 4% 이하) 안에서만 쓴다. lint의 T.jyo_ratio, T.geudeun_ratio, T.neundeyo_ratio가 비율을 센다.

- ~거든요: Default 문장에 원인 표지(때문, ~므로, ~어서, ~니까)가 있을 때만 쓴다. 원인 표지가 없는 문장에 쓰면 자료에 없는 인과 관계를 만든다. "이유는 ~때문입니다"처럼 주어가 이미 이유를 말하는 문장에는 쓰지 않는다.
  - D: 쓰기 비율이 높은 서비스에서는 처리량이 15% 떨어졌습니다. 메시지를 더 자주 보내기 때문입니다.
  - C: 쓰기 비율이 높은 서비스에서는 처리량이 15% 떨어졌어요. 메시지를 더 자주 보내거든요.
- ~죠: 앞 문장의 내용에서 바로 나오는 귀결을 다시 말할 때만 쓴다. 새 사실에 쓰면 독자가 이미 안다고 전제하게 된다.
  - D: 배치가 작을수록 보내는 메시지 수도 늘어납니다.
  - C: 배치가 작을수록 보내는 메시지 수도 늘어나죠.
- ~는데요: 다음 문장이 대조나 보충을 이어 갈 때만 쓴다. 문장의 내용은 바뀌지 않는다.
  - D: 배치 크기를 줄이면 지연이 줄어듭니다. 쓰기 비율이 높은 서비스에서는 처리량이 15% 떨어졌습니다.
  - C: 배치 크기를 줄이면 지연이 줄어드는데요. 쓰기 비율이 높은 서비스에서는 처리량이 15% 떨어졌어요.
- 축약: 것은 → 건, 것이 → 게, 것을 → 걸, 이것은 → 이건. tone_check는 같은 어절로 본다.

## 쓰지 않는 Casual 표현

- ~더라고요, ~더군요, ~네요: 글쓴이가 직접 겪거나 보고 놀랐다는 뜻이 된다. 자료를 정리하는 글에서는 지어낸 경험이 된다(rubric G2).
- ~잖아요: 독자가 이미 안다고 전제한다.
- ~답니다, 반말(~해, ~야), 이모지, 느낌표, "완전", "진짜", "엄청" 같은 구어 강조어

## 예

가상의 논문(김 등 2025, 캐시 무효화 지연 측정)을 정리하는 문장이다.

| Default | Casual |
|---|---|
| 저자들은 12개 서비스의 로그 3억 건을 분석했습니다. | 저자들은 12개 서비스의 로그 3억 건을 분석했어요. |
| 지연의 72%는 배치 대기에서 생겼습니다. | 지연의 72%는 배치 대기에서 생겼어요. |
| 이렇게 나눠 재는 것은 대기 시간과 전송 시간을 따로 보기 위해서입니다. | 이렇게 나눠 재는 건 대기 시간과 전송 시간을 따로 보기 위해서예요. |
| 어떻게 지연을 줄였을까요? | 어떻게 지연을 줄였을까요? |
| 배치 크기를 10으로 줄인 설정이 가장 빠른 방법입니다. | 배치 크기를 10으로 줄인 설정이 가장 빠른 방법이에요. |
